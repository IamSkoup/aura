# Aura Wear

Сайт: [iamskoup.github.io/aura](https://iamskoup.github.io/aura/). Публикация выполняется автоматически из ветки `main` через GitHub Actions. Это статическая версия: для её работы не нужен Next.js, сервер, платный тариф Firebase или банковская карта.

## Инструкция для владельца Aura Wear

### Что доступно сейчас

Каталог содержит визуальные образцы. Конструктор футболки позволяет менять цвет и размер, загружать изображения, добавлять надписи, рисовать кистью, двигать и поворачивать слои, смотреть изделие в 3D и сохранять проекты в браузере. Корзина также хранится в браузере. **Оплата и отправка заказа не работают:** сайт прямо сообщает об этом посетителям. Очистка данных браузера удалит сохранённые проекты.

Присланная серверная версия сохранена в ветке [`uploaded-next`](https://github.com/IamSkoup/aura/tree/uploaded-next). Более ранняя серверная версия находится в [`server-archive`](https://github.com/IamSkoup/aura/tree/server-archive).

### Как открыть и обновлять сайт

1. Откройте [Settings → Pages](https://github.com/IamSkoup/aura/settings/pages) и выберите **Build and deployment → Source: GitHub Actions**. Первый запуск может потребовать подтверждения GitHub Pages в настройках репозитория.
2. После каждого обновления `main` дождитесь зелёного результата в [Actions](https://github.com/IamSkoup/aura/actions/workflows/pages.yml).
3. Откройте [публичный сайт](https://iamskoup.github.io/aura/). Иногда новая версия появляется спустя несколько минут.

Для запуска на своём компьютере установите Node.js 22, выполните `npm ci`, затем `npm run dev`. Команда `npm run build` создаёт готовые файлы в `dist-pages`. Проверки: `npm run typecheck` и `npm test`.

### Firebase на бесплатном тарифе Spark

Публичные настройки веб-приложения указаны в `static-site/firebase.ts`. В консоли Firebase откройте **Authentication → Sign-in method** и включите Email/Password. В **Authentication → Settings → Authorized domains** добавьте `iamskoup.github.io`. Для чтения опубликованных товаров из Realtime Database примените правила из `database.rules.json` в разделе **Realtime Database → Rules**. Не добавляйте сервисный ключ Firebase Admin в репозиторий: он не нужен статическому сайту.

### Каталог и реальные товары

Образцы описаны в `static-site/catalog.ts`, изображения — в `public/images`. У образцов нет реальной цены и возможности покупки. Чтобы открыть продажи, владелец должен предоставить фотографии с правами использования, SKU, цены, остатки, цвета, размеры, состав, фактическую таблицу размеров и размеры печатных зон. Публикуйте проверенные данные в Realtime Database в узле `products`; карточки с `published: true` будут показаны рядом с образцами. Публичные изображения размещайте по HTTPS либо в `public/images`. Не публикуйте исходники покупателей в Realtime Database.

### Как подключить ЮKassa и настоящие заказы

GitHub Pages не может безопасно принимать оплату: секретный ключ ЮKassa и проверка уведомлений должны работать на сервере. Начните с ветки `uploaded-next` на серверном хостинге. Владелец магазина должен получить договор, Shop ID и секретный ключ ЮKassa, предоставить реквизиты, данные для чеков и необходимые правовые документы. Укажите секреты в настройках серверного хостинга, настройте адрес уведомлений `/api/payments/webhook` и проверьте создание платежа, подписанное/проверенное уведомление, повторные webhook-события, отмену и возврат. Только сервер должен вычислять цену и создавать заказ. До завершения этих шагов кнопка оплаты на статическом сайте остаётся недоступной.

### Файлы, доставка и производство

Для оригинальных фото и макетов печати потребуется приватное файловое хранилище с серверной загрузкой. Подойдут Firebase Storage при доступном тарифе или S3-совместимый сервис; стоимость зависит от провайдера. Настройте проверку формата, размера и прав доступа. Для доставки заключите договор с перевозчиком или задайте собственные тарифы, сроки, города и способы выдачи; расчёт и подтверждение заказа должны выполняться на сервере. Прежде чем принимать заказы, согласуйте требования типографии к физическому размеру печати и DPI. Браузерный 3D-просмотр не является производственным файлом.

### Что может потребовать оплаты

Публикация этого сайта на GitHub Pages и базовое использование Firebase Spark могут быть бесплатными в пределах лимитов. Для коммерческого запуска могут потребовать оплаты серверный хостинг, объектное хранилище, домен, платёжные комиссии, онлайн-касса, доставка и превышение лимитов Firebase. Не подключайте платные сервисы без согласования с владельцем бизнеса.
